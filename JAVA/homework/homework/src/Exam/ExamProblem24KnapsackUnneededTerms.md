# 24번 풀이 - P[3][50] 계산에 필요 없는 항

## 문제 정리

아이템 정보는 다음과 같다.

| 아이템 | 무게 | 값 |
|---|---:|---:|
| 1 | 10kg | 50 |
| 2 | 20kg | 60 |
| 3 | 30kg | 140 |

구하려는 값은 `P[3][50]`이다.

## 풀이 과정

3번 아이템을 기준으로 점화식을 적용한다.

```text
P[3][50] = max(P[2][50], 140 + P[2][20])
```

따라서 2단계에서 필요한 항은 다음뿐이다.

```text
P[2][50], P[2][20]
```

이를 다시 2번 아이템 기준으로 풀면 다음과 같다.

```text
P[2][50] = max(P[1][50], 60 + P[1][30])
P[2][20] = max(P[1][20], 60 + P[1][0])
```

따라서 필요한 항은 다음이다.

```text
P[2][50], P[2][20], P[1][50], P[1][30], P[1][20], P[1][0]
```

보기 중 `P[1][0]`은 없으므로, 보기에서 계산할 필요가 없는 항은 나머지 의존 관계에 없는 항들이다.

## 정답

```text
P[2][40], P[2][30], P[2][10], P[1][40], P[1][10]
```

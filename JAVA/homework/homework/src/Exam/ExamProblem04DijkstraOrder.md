# 4번 풀이 - Dijkstra 최단경로 발견 순서

## 문제 정리

2번 그래프에서 출발점은 `v3`이다.  
나머지 정점들에 대해 최단경로가 확정되는 순서를 구한다.

## 초기 거리

`v3`에서 직접 갈 수 있는 간선은 다음과 같다.

```text
dist[v1] = 3
dist[v2] = 7
dist[v4] = 8
```

## 풀이 과정

1. 가장 가까운 정점은 `v1`, 거리 `3`이다.
2. `v1 -> v2`의 비용이 `2`이므로 `v2` 거리가 갱신된다.

```text
dist[v2] = min(7, 3 + 2) = 5
```

3. 다음으로 가까운 정점은 `v2`, 거리 `5`이다.
4. `v2`를 거쳐도 `v4`는 `5 + 4 = 9`이므로 기존 `8`보다 크다.
5. 마지막으로 `v4`, 거리 `8`이 확정된다.

## 정답

```text
v1 -> v2 -> v4
```

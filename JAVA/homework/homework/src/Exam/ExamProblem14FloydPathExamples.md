# 14번 풀이 - D(1), D(2)에서 변경되는 경로 예

## 문제 정리

주어진 무방향 그래프를 `D(0)`으로 보고 Floyd-Warshall을 적용한다.  
`D(1)`은 정점 `1`을 중간 정점으로 사용할 수 있고, `D(2)`는 정점 `1`, `2`를 중간 정점으로 사용할 수 있다.

## D(1)에서 변경되는 경로 예

정점 `2`와 `4` 사이에는 직접 간선이 없다.  
하지만 정점 `1`을 중간 정점으로 사용하면 경로가 생긴다.

```text
2 -> 1 -> 4
비용 = 11 + 17 = 28
```

따라서 `D(1)`에서 `D[2][4]`는 `∞`에서 `28`로 변경된다.

## D(2)에서 변경되는 경로 예

정점 `1`과 `5` 사이에도 직접 간선이 없다.  
정점 `2`까지 중간 정점으로 허용하면 다음 경로가 가능하다.

```text
1 -> 2 -> 5
비용 = 11 + 45 = 56
```

따라서 `D(2)`에서 `D[1][5]`는 `∞`에서 `56`으로 변경된다.

## 정답

| 구분 | 변경되는 경로 예 |
|---|---|
| `D(1)` | `2 -> 1 -> 4`, 비용 `28` |
| `D(2)` | `1 -> 2 -> 5`, 비용 `56` |

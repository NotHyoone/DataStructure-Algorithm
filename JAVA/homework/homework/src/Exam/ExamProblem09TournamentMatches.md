# 9번 풀이 - 토너먼트 전체 경기 수

## 문제 정리

`n = 2^k`개의 팀이 참가하고, 한 번 지면 탈락하는 토너먼트이다.  
각 경기에서는 정확히 한 팀이 탈락한다.

## ① 64팀일 때 전체 경기 수

우승팀 1팀만 남아야 하므로 탈락해야 하는 팀은 `64 - 1 = 63`팀이다.  
경기 1번마다 1팀이 탈락하므로 전체 경기 수는 다음과 같다.

```text
63경기
```

## ② 재현식과 해

첫 회전에서 `n/2`경기가 열리고, `n/2`팀이 다음 회전에 진출한다.

```text
T(1) = 0
T(n) = T(n/2) + n/2
```

전개하면 다음과 같다.

```text
T(n) = n/2 + n/4 + n/8 + ... + 1
     = n - 1
```

## 정답

```text
T(64) = 63
T(n) = T(n/2) + n/2, T(1) = 0
T(n) = n - 1
```

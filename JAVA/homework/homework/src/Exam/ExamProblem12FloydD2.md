# 12번 풀이 - D(2)에서 D(0)와 달라지는 항

## 문제 정리

`D0`가 주어졌을 때 Floyd-Warshall 방식으로 `D2`를 구한다.  
`D2`는 중간 정점으로 `1`, `2`를 사용할 수 있을 때의 최단거리 행렬이다. 문제는 `D0`와 값이 다른 항만 표시하라고 했다.

## D0

| from \ to | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|
| 1 | 0 | 4 | ∞ | ∞ | 10 |
| 2 | 3 | 0 | ∞ | 18 | ∞ |
| 3 | ∞ | 6 | 0 | ∞ | ∞ |
| 4 | ∞ | 5 | 15 | 0 | 19 |
| 5 | ∞ | ∞ | ∞ | 4 | 0 |

## 계산 과정

### D1에서 변경되는 항

중간 정점 `1`을 허용하면 다음 항이 바뀐다.

```text
D1[2][5] = min(∞, D0[2][1] + D0[1][5])
         = min(∞, 3 + 10)
         = 13
```

### D2에서 추가로 변경되는 항

중간 정점 `2`까지 허용하면 다음 항들이 바뀐다.

```text
D2[1][4] = 4 + 18 = 22
D2[3][1] = 6 + 3 = 9
D2[3][4] = 6 + 18 = 24
D2[3][5] = 6 + 13 = 19
D2[4][1] = 5 + 3 = 8
D2[4][5] = min(19, 5 + 13) = 18
```

## 정답

`D0`와 값이 다른 항만 표시하면 다음과 같다.

| from \ to | 1 | 2 | 3 | 4 | 5 |
|---|---:|---:|---:|---:|---:|
| 1 |  |  |  | 22 |  |
| 2 |  |  |  |  | 13 |
| 3 | 9 |  |  | 24 | 19 |
| 4 | 8 |  |  |  | 18 |
| 5 |  |  |  |  |  |

# 8번 풀이 - P[3][30] 계산에 필요 없는 항

## 문제 정리

아이템 정보는 다음과 같다.

| 아이템 | 무게 | 값 |
|---|---:|---:|
| 1 | 5kg | 50 |
| 2 | 10kg | 60 |
| 3 | 20kg | 140 |

구하려는 값은 `P[3][30]`이다.

## 풀이 과정

0/1 배낭 점화식은 다음과 같다.

```text
P[i][w] = max(P[i-1][w], p[i] + P[i-1][w-w[i]])  if w[i] <= w
P[i][w] = P[i-1][w]                              if w[i] > w
```

먼저 3번 아이템을 기준으로 계산한다.

```text
P[3][30] = max(P[2][30], 140 + P[2][10])
```

따라서 직접 필요한 2단계 항은 다음뿐이다.

```text
P[2][30], P[2][10]
```

각 항을 한 단계 더 풀면 다음과 같다.

```text
P[2][30] = max(P[1][30], 60 + P[1][20])
P[2][10] = max(P[1][10], 60 + P[1][0])
```

보기 중 `P[2][20]`은 위 의존 관계에 등장하지 않는다.

## 정답

```text
③ P[2][20]
```

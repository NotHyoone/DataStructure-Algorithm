# 2번 풀이 - TSP 동적 계획 값 계산

## 문제 정리

출발점은 `v1`이고, 구해야 하는 값은 `D[v3][{v2, v4}]`이다.  
여기서 `D[i][A]`는 정점 `i`에서 출발해 집합 `A`의 정점을 모두 방문한 뒤 시작점 `v1`로 돌아가는 최소 비용이다.

## 그래프에서 읽은 간선

필요한 간선만 정리하면 다음과 같다.

| 간선 | 비용 |
|---|---:|
| `v2 -> v1` | 1 |
| `v3 -> v2` | 7 |
| `v3 -> v4` | 8 |
| `v4 -> v1` | 6 |
| `v4 -> v2` | 3 |

## 풀이 과정

기저 조건은 다음과 같다.

```text
D[v2][∅] = W[v2][v1] = 1
D[v4][∅] = W[v4][v1] = 6
```

부분 문제를 먼저 계산한다.

```text
D[v2][{v4}] = W[v2][v4] + D[v4][∅]
             = 4 + 6
             = 10

D[v4][{v2}] = W[v4][v2] + D[v2][∅]
             = 3 + 1
             = 4
```

따라서 최종 값은 다음과 같다.

```text
D[v3][{v2, v4}]
= min(
    W[v3][v2] + D[v2][{v4}],
    W[v3][v4] + D[v4][{v2}]
  )
= min(7 + 10, 8 + 4)
= min(17, 12)
= 12
```

## 정답

```text
D[v3][{v2, v4}] = 12
```

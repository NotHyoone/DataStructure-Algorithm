# 16번 풀이 - Prim과 Kruskal 설명 중 잘못된 것

## 보기 검토

① `Prim 알고리즘의 성능은 e의 크기와 관계가 없다.`

수업에서 흔히 쓰는 인접 행렬 기반 Prim 구현은 `O(n^2)`이므로 `e`에 직접 의존하지 않는다고 볼 수 있다. 단, 우선순위 큐와 인접 리스트로 구현하면 `O(e log n)`이므로 구현 방식에 따라 달라진다.

② `Kruskal 알고리즘에서는 cycle 검사가 필요하다.`

맞다. 같은 집합에 속한 두 정점을 연결하면 cycle이 생기므로 union-find로 검사한다.

③ `두 알고리즘 모두 동적 프로그래밍을 이용하여 구현한다.`

틀리다. Prim과 Kruskal은 대표적인 greedy algorithm이다.

④ `n이 커질수록 두 알고리즘 모두 실행 시간이 오래 걸린다.`

맞다. 정점 수가 증가하면 처리해야 할 후보 정점이나 간선도 증가한다.

⑤ `Dense graph에서는 Prim 알고리즘의 성능이 Kruskal 알고리즘보다 우수하다.`

교재식 비교에서는 맞는 설명이다. Dense graph에서는 간선 수가 많아 Kruskal의 정렬 비용이 커진다.

주의: ①은 구현 방식에 따라 해석이 달라질 수 있지만, 시험 문맥상 인접 행렬 Prim을 기준으로 보면 맞는 설명으로 처리하는 것이 자연스럽다.

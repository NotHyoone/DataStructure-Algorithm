# 22번 풀이 - QuickSort 평균 시간 점화식

## 문제 정리

11번과 같은 유형이다. 크기 `n`인 정수 배열을 빠른 정렬로 정렬할 때 평균 시간 `A(n)`을 점화식으로 표현한다.

## 풀이 과정

피벗이 최종적으로 왼쪽에 `i`개, 오른쪽에 `n - i - 1`개를 남긴다고 하자.  
평균적으로 피벗 위치가 `0`부터 `n - 1`까지 균등하게 나타난다고 보면 다음과 같다.

```text
A(n) = (1/n) * Σ(i = 0 to n-1) { A(i) + A(n - i - 1) } + cn
```

대칭성을 이용하면 다음처럼 줄여 쓸 수도 있다.

```text
A(n) = (2/n) * Σ(i = 0 to n-1) A(i) + cn
```

## 정답

```text
A(0) = A(1) = O(1)
A(n) = (1/n) * Σ(i = 0 to n-1) { A(i) + A(n - i - 1) } + cn
```

해는 평균적으로 `O(n log n)`이다.

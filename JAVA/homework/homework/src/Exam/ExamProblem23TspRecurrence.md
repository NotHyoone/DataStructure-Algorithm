# 23번 풀이 - TSP 동적 계획 점화식

## 문제 정리

방향성 그래프가 가중치 인접 행렬 `W[n][n]`으로 주어진다.  
정점 `0`에서 출발해 나머지 정점을 모두 방문한 뒤 다시 `0`으로 돌아오는 최단 경로를 구한다.

`D[i][A]`는 다음 의미를 가진다.

```text
정점 i에서 출발해 집합 A에 속한 정점들을 모두 방문한 뒤 0으로 돌아가는 최단 경로 길이
```

기저 조건은 다음과 같다.

```text
D[i][∅] = W[i][0]
```

## 점화식

`A`가 공집합이 아니면, 다음에 방문할 정점 `j`를 `A` 안에서 하나 선택한다.

```text
D[i][A] = min { W[i][j] + D[j][A - {j}] | j ∈ A }
```

## 풀이 의미

`i`에서 바로 `j`로 이동하는 비용 `W[i][j]`를 먼저 더한다.  
그 뒤에는 `j`에서 출발하여 나머지 정점 `A - {j}`를 모두 방문하고 `0`으로 돌아가면 된다.  
모든 가능한 `j` 중 최소값을 고르면 `D[i][A]`가 된다.

## 정답

```text
D[i][A] = min_{j ∈ A} (W[i][j] + D[j][A - {j}])
```

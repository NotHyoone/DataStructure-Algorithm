# 11번 풀이 - 빠른 정렬 평균 시간 점화식

## 문제 정리

크기 `n`인 배열을 QuickSort로 정렬할 때 평균 시간 `A(n)`을 점화식으로 나타낸다.

## 풀이 과정

피벗이 정렬 후 `i`번째 위치에 놓인다고 하면 왼쪽 부분 배열 크기는 `i`, 오른쪽 부분 배열 크기는 `n - i - 1`이다.

피벗 위치가 평균적으로 모든 위치에 동일하게 나타난다고 보면 평균 시간은 다음과 같다.

```text
A(n) = (1/n) * Σ(i = 0 to n-1) { A(i) + A(n - i - 1) } + cn
```

여기서 `cn`은 분할 과정에서 배열을 한 번 훑는 비용이다.

동치 형태로는 다음처럼 쓸 수 있다.

```text
A(n) = (2/n) * Σ(i = 0 to n-1) A(i) + cn
```

## 정답

```text
A(0) = A(1) = O(1)
A(n) = (1/n) * Σ(i = 0 to n-1) { A(i) + A(n - i - 1) } + cn
```

이 점화식의 해는 평균적으로 `O(n log n)`이다.

# 3번 풀이 - Floyd-Warshall의 D(1) 행렬

## 문제 정리

2번의 방향 그래프에 대해 all-pairs shortest path를 구한다.  
`D(1)`은 중간 정점으로 `v1`만 사용할 수 있을 때의 최단거리 행렬이다.

## D(0) 행렬

PDF의 그래프를 인접 행렬로 쓰면 다음과 같다.

| from \ to | v1 | v2 | v3 | v4 |
|---|---:|---:|---:|---:|
| v1 | 0 | 2 | ∞ | ∞ |
| v2 | 1 | 0 | 6 | 4 |
| v3 | 3 | 7 | 0 | 8 |
| v4 | 6 | 3 | 2 | 0 |

## 계산 과정

`D(1)[i][j] = min(D(0)[i][j], D(0)[i][1] + D(0)[1][j])`

`v1`을 경유해서 개선되는 대표 항은 다음 하나이다.

```text
D(1)[v3][v2] = min(7, D(0)[v3][v1] + D(0)[v1][v2])
             = min(7, 3 + 2)
             = 5
```

다른 항들은 `v1`을 경유해도 더 짧아지지 않거나, 경유 경로가 존재하지 않는다.
